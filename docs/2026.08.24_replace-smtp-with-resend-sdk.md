# SMTP → Resend SDK 교체

## 배경

`gomail` + SMTP(`smtp.resend.com`) 방식은 서버 outbound SMTP 포트 차단 등으로 인해 이메일 발송이 실패함.  
Resend Go SDK(`github.com/resend/resend-go/v3`)는 HTTPS API를 사용하므로 포트 이슈 없음.

## 변경 파일

### 1. `internal/infra/smtp.go`

- `gomail.Dialer` → `resend.Client` 로 교체
- `NewSMTP(cfg)` → `NewMailer(cfg)` 로 이름 변경
- `Mailer.Send(to, subject, body string) error` 시그니처 유지 (service 레이어 변경 없음)

### 2. `config/config.go`

- `SMTPConfig` 제거 → `ResendConfig` 추가
- 환경변수: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` (5개) → `RESEND_API_KEY`, `RESEND_FROM` (2개)

### 3. `cmd/server/main.go`

- `infra.NewSMTP(cfg)` → `infra.NewMailer(cfg)`

### 4. `.env.example`

- SMTP 관련 항목 제거, Resend 항목 추가

## 환경변수

| 키 | 값 예시 | 설명 |
|----|---------|------|
| `RESEND_API_KEY` | `re_xxxxxxxx` | Resend API 키 |
| `RESEND_FROM` | `noreply@heijionline.com` | 발신자 (heijionline.com 도메인 한정) |

## 데이터 흐름

변경 없음. `Mailer.Send()` 인터페이스 유지로 `service/auth.go` 무변경.
