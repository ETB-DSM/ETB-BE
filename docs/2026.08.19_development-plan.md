# Development Plan

## 개발 단계 개요

총 7개 Phase로 나누어 진행한다. 각 Phase는 이전 Phase에 의존하므로 순서를 지킨다.

```
Phase 1: 프로젝트 기반 세팅
    ↓
Phase 2: DB 스키마 & sqlc
    ↓
Phase 3: 공통 인프라 (에러 핸들링, 미들웨어)
    ↓
Phase 4: 인증 (회원가입 / 로그인 / JWT)
    ↓
Phase 5: 디바이스 & 보호자 관리
    ↓
Phase 6: 핵심 비즈니스 기능 (목적지 / SOS)
    ↓
Phase 7: WebSocket / OCR 로그 (선택)
```

## Phase 4 — 인증

**목표:** 회원가입, 이메일 인증, 로그인(이메일/Google), 토큰 갱신, 로그아웃

### 생성 파일

```
internal/handler/auth.go
internal/service/auth.go
internal/domain/user.go
```

### 엔드포인트 및 로직

| 엔드포인트 | 핵심 로직 |
|-----------|----------|
| `POST /auth/signup` | bcrypt 해시 → DB 저장(email_verified=false) → 6자리 코드 생성 → Redis `verify:{email}` TTL 5분 → SMTP 발송 |
| `POST /auth/verify-email` | Redis 코드 비교 → 일치 시 email_verified=true → Redis 키 삭제 |
| `POST /auth/login` | 비밀번호 검증 → email_verified 확인 → Access Token(15분) + Refresh Token(7일) 발급 → Redis `refresh:{userId}` 저장 |
| `POST /auth/login/google` | `idtoken.Validate()` → email 추출 → DB 조회/생성 → JWT 발급 |
| `POST /auth/refresh` | Refresh Token 서명 검증 → Redis 존재 확인 → 새 Access Token 발급 |
| `POST /auth/logout` | Redis `refresh:{userId}` 삭제 |

### DTO (`internal/domain/user.go`)

```go
type SignupRequest struct {
    Email    string `json:"email"    binding:"required,email"`
    Nickname string `json:"nickname" binding:"required"`
    Password string `json:"password" binding:"required,min=8"`
}

type VerifyEmailRequest struct {
    Email string `json:"email" binding:"required,email"`
    Code  string `json:"code"  binding:"required,len=6"`
}

type LoginRequest struct {
    Email    string `json:"email"    binding:"required,email"`
    Password string `json:"password" binding:"required"`
}

type GoogleLoginRequest struct {
    IDToken string `json:"idToken" binding:"required"`
}

type TokenResponse struct {
    AccessToken  string `json:"accessToken"`
    RefreshToken string `json:"refreshToken,omitempty"`
}
```

### WebSocket 메시지 처리 흐름

```
연결 시: JWT 검증 + deviceId 소유권 확인

    type == "location"      → ack 응답

60초 read deadline, Ping/Pong으로 연결 유지
```

## 라우터 등록 구조 (`cmd/server/main.go`)

```go
r := gin.New()
r.Use(middleware.Logger(), gin.Recovery(), cors.Default())

auth := r.Group("/auth")
{
    auth.POST("/signup", authHandler.Signup)
    auth.POST("/verify-email", authHandler.VerifyEmail)
    auth.POST("/login", authHandler.Login)
    auth.POST("/login/google", authHandler.LoginGoogle)
    auth.POST("/refresh", authHandler.Refresh)
    auth.POST("/logout", middleware.Auth(cfg), authHandler.Logout)
}

api := r.Group("/", middleware.Auth(cfg))
{
    api.POST("/devices", deviceHandler.Create)
    api.GET("/devices", deviceHandler.List)
    api.DELETE("/devices/:deviceId", deviceHandler.Delete)

    api.POST("/guardians", guardianHandler.Create)
    api.GET("/guardians", guardianHandler.List)
    api.DELETE("/guardians/:guardianId", guardianHandler.Delete)

    api.POST("/destinations", destinationHandler.Create)
    api.GET("/destinations", destinationHandler.List)
    api.DELETE("/destinations/:destinationId", destinationHandler.Delete)

    api.POST("/sos", sosHandler.Create)
    api.GET("/sos", sosHandler.List)

    api.POST("/ocr-logs", ocrHandler.Create) // 선택
}

r.GET("/ws/device", wsHandler.Handle)
```
